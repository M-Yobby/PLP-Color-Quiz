# 🎨 Quiz Game 

This project is a simple Python program that allows users to enter a color and then guess which category it belongs to.

---

## 📌 Features
- Accepts a color from the user.
- Categorizes colors into:
  - **Primary**: red, green, blue
  - **Secondary**: yellow, cyan, magenta
  - **Tertiary**: orange, purple, pink
  - **Neutral**: black, white, gray
  - **Metallic**: brown, gold, silver
  - **Earthy**: teal, navy, olive
- Checks the user's category guess.
- Informs the user if a color is **unknown**.

---

## 🖥️ Example Usage
```
Pick a color: red
You chose the color red.
Enter the category: primary
Correct! red is a primary color.
```

If the color is unknown:
```
Pick a color: indigo
You chose the color indigo.
Enter the category: tertiary
The color indigo is not in the list of known colors.
```

## ▶️ How to Run in VS Code
1. Make sure **Python** is installed on your computer.
2. Install **VS Code** and the **Python extension**.
3. Open VS Code and navigate to the folder containing the script (e.g., `Quiz Game.py`).
4. Open the script file in VS Code.
5. Click **Run** ▶ at the top-right corner or press **Ctrl+F5** to run the program.
6. Follow the prompts in the **Terminal**.
